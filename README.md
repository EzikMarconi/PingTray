# PingTray

PingTray — небольшое приложение для Windows, которое остаётся в системном трее и периодически пингует выбранный хост по ICMP. Иконка показывает состояние сети: нормальная задержка, повышенная или ошибка.

## Возможности

- Фоновый мониторинг доступности хоста (ICMP ping).
- Иконка в трее в реальном времени:
  - **зелёная** — пинг успешен, время отклика не превышает порог «жёлтой» зоны;
  - **жёлтая** — пинг успешен, но задержка выше этого порога;
  - **красная** — ошибка пинга или сеть недоступна.
- Подсказка на иконке: статус и время отклика (или текст ошибки).
- **Настройки из меню трея** — целевой хост, порог жёлтой зоны, таймаут ping и интервал между запросами **без правки кода и пересборки**.
- Сохранение параметров в файл на диске; при следующем запуске подхватываются автоматически.

- Windows 10/11

## Быстрый старт

```powershell
dotnet restore .\PingTray.slnx
dotnet build .\PingTray.slnx -c Release
dotnet run --project .\PingTray\PingTray.csproj
```

После запуска окно не показывается: работа идёт из трея (рядом с часами).

## Настройки

1. Щёлкните правой кнопкой по иконке PingTray в трее.
2. Выберите **«Настройки…»**.
3. Укажите параметры и нажмите **OK** — они сохраняются и сразу применяются к циклу пинга (перезапуск не обязателен).

### Где хранится файл

JSON-файл с настройками:

`%LocalAppData%\PingTray\settings.json`

(обычно `C:\Users\<имя>\AppData\Local\PingTray\settings.json`).

Если файла нет или он повреждён, используются значения по умолчанию из кода.

### Значения по умолчанию

| Параметр | По умолчанию | Смысл |
|----------|----------------|--------|
| Целевой хост | `77.88.55.242` | IP или DNS-имя (например, узел Yandex) |
| Порог «жёлтой» зоны | `150` мс | До этого значения включительно — зелёная иконка, выше — жёлтая |
| Таймаут ping | `3000` мс | Ожидание ответа на один запрос |
| Интервал между ping | `500` мс | Пауза между последовательными запросами |

Логика порога и пути к файлу заданы в `PingTray/AppSettings.cs`; меню и диалог — в `PingTray/Program.cs` и `PingTray/SettingsForm.cs`.
