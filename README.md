# PingTray

PingTray - это простое приложение для Windows, которое живет в системном трее и постоянно пингует указанный хост. Иконка в трее показывает текущее состояние сети: хороший отклик, задержка или ошибка.

## Возможности

- Мониторинг доступности хоста через ICMP ping в фоне.
- Обновление иконки в трее в реальном времени:
  - зеленая - пинг успешный и быстрый (<= 150 мс),
  - желтая - пинг успешный, но медленный (> 150 мс),
  - красная - ошибка пинга или недоступность сети.
- Подсказка на иконке с текущим статусом/временем ответа.
- Контекстное меню в трее с пунктом "Выход".

## Технологии

- C#
- .NET 8
- Windows Forms (`NotifyIcon`, `ContextMenuStrip`)

## Требования

- Windows 10/11
- .NET SDK 8.0+ (для сборки из исходников)

## Быстрый старт

```powershell
dotnet restore .\PingTray.slnx
dotnet build .\PingTray.slnx -c Release
dotnet run --project .\PingTray\PingTray.csproj
```

После запуска приложение не открывает окно и работает в трее.

## Поведение приложения

- Целевой адрес по умолчанию: `77.88.55.242`. (Yandex)
- Таймаут одного ping-запроса: `3000` мс.
- Интервал между запросами: `500` мс.

Эти значения задаются в `PingTray/Program.cs`.

## Как изменить целевой хост

Откройте файл `PingTray/Program.cs` и измените значение поля:

```csharp
private static readonly string _target = "77.88.55.242";
```

Например, можно подставить адрес вашего шлюза, DNS-сервера или внешнего узла.

## Выход из программы

Нажмите правой кнопкой по иконке в трее и выберите "Выход".
